# 真实演示录制脚本（3–5 分钟）

本脚本只供用户实际操作和录制。尚无录像；离线回放不能充当微信收发证据。
可将主平台 3 分钟操作与另一平台约 1 分钟补充片组合，平台切换和剪辑明确标注。
仅展示指定测试好友；隐藏账号、昵称、其他会话、模型密钥、数据库目录和通知。

| 时段 | 用户操作 | 核对与画面 |
| --- | --- | --- |
| 0:00–0:30 | 展示系统/微信版本，启动 `uv run wechat-agent serve`，打开工作台 | 默认 stopped / dry-run；声明平台和实际限制；Mac 显式降级时人工清空草稿、保持绑定独立窗打开 |
| 0:30–1:00 | 配置白名单和模型，导入 `examples/knowledge/fictional-tea-shop.md`，检索“桂花乌龙茶” | 展示实际导入片段数和来源；知识/记忆会发送给配置的模型；密钥掩码 |
| 1:00–2:10 | 明确选择 live，点击开始。测试好友依次发“你好，周末想喝茶”“春山茶铺的桂花乌龙茶多少钱？”“那周三能去吗？” | 每轮收到完整回复后再发下一轮；真实等待至少 30 秒发送间隔，未剪等待如实保留或标明；知识来源与追问上下文正确；默认每次最多 3 条后停发，可在设置调整 |
| 2:10–3:10 | 停止状态查看知识来源、执行时间线；重新开始后发“记住我的偏好：饮品=乌龙茶”，核对记忆；暂停、恢复，好友问“我偏好什么饮品？” | 展示明确偏好已保存、暂停无额外回复、恢复重建基线；重启服务验证记忆仍在，启动默认 stopped / dry-run |
| 3:10–3:50 | 在停止状态更正为“白茶”、再次开始询问；停止并忘记该偏好；删除知识后测试检索 | 更正/忘记返回真实成功；旧上下文已清空；删除知识不再召回；无命中有明确状态。超过片长可保留完整原片并做标注剪辑 |
| 3:50–4:50 | 切到另一平台的真实片段：版本、工作台、知识问答/偏好、对端收件 | 另一平台独立账号绑定与真实运行，不复用主平台证据。Windows 原生回归、Mac 严格 G1/G2 缺失时明确保留未通过状态 |

录制前按 [交付清单](delivery-checklist.md) 完成实测并更新公开脱敏摘要。不要为录制刻意制造 unknown；该故障分支用标注为 offline 的回放报告说明。
演示不包含订单/工单、PDF/DOCX、语音识别；Phase 8 未选择。

录像后播放完整视频，确认文字清晰、声音可用、两平台画面与实际收件一致，并检查个人信息。
如果使用多段原片，用户剪成包含两平台片段的主文件，再执行 `package --video`。ffprobe 只证明媒体可解析，不证明内容或隐私已经人工核实。
