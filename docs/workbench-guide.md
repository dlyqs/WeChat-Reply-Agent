# Reply Studio 工作台使用指南

新版工作台包含工作概览、会话与记录、知识库、联系人记忆和设置。界面人工验收仍由用户完成；本轮没有打开页面或操作真实微信。

## 1. 启动新版

在项目根目录先停止旧服务（原终端 Ctrl+C），再执行：

```sh
./.local/tooling/bin/uv run wechat-agent serve
```

打开 http://127.0.0.1:8765 。如果终端已安装 uv，也可以使用 `uv run wechat-agent serve`。
服务启动时默认停止、仅生成回复，不会自动连接微信或发送消息。若页面提示新接口不存在，需要重启旧服务并刷新页面。

## 2. 先配置模型与回复风格

1. 打开「设置 → 模型连接」，选择 DeepSeek 或自定义兼容服务，填写模型根地址、模型名称和密钥。根地址不带 `/chat/completions`，保留服务商要求的 `/v1` 等前缀。
2. 点击「测试连接」，只发送一条简短的模型测试请求，不操作微信，也不会自动保存修改。测试可能产生少量模型费用。
3. 在「回复风格」选择「小北 · 跨境产品助理」。完整提示词覆盖语气、产品依据、缺失资料、售后排障、身份诚实和操作边界，并将推荐输入预算8192、输出预算256放入草稿。
4. 点击底部「保存设置」。切换工作台页面会保留未保存草稿；刷新整个浏览器页面会丢弃草稿。运行中先暂停，再保存。

日常聊天可选「自然日常助理」。也可以展开完整提示词自行编辑；选择预设不会改动密钥、好友名单或自动开启真实发送。
「在微信回复末尾显示资料来源」默认关闭，聊天更自然；采用的来源始终在工作台执行详情中保留。

## 3. 使用内置跨境电商知识库

「知识库」内置 **NORTHLINE 北线咖啡**，一家虚构的便携咖啡器具公司，面向美国和欧盟销售手压意式咖啡机、手摇磨豆机及收纳配件。

首次启动会准备5份原始资料，但默认未启用，避免混入现有业务。进入示例后点击「启用知识库」。资料包含公司和品牌、产品手册、内部实测、仓储物流及售后排障；所有参数、库存、批次和政策都是原创虚构数据，不对应真实公司或商业承诺。

在右侧测试面板可以：

- 「仅查资料」：本机 FTS5 检索，不调用模型。显示实际命中的原文片段。
- 「生成模拟回复」：使用已保存的模型和人设、当前已启用知识库及当前模拟对话，生成一条实际模型回复。不会发送微信、不写入真实会话或联系人记忆。模拟对话会保留最近几轮上下文，切换知识库或离开页面后重置。
- 「核对这题的预期要点」：对照内置答案要点，不能把预期答案当成已经通过的模型实测结论。

推荐测试：

| 问题 | 正确回答应包含 |
| --- | --- |
| T7 的冬季密封圈内部编号是什么？适合什么温度？ | NR-24B，环境5–15℃，不用于零下萃取 |
| T7 在海拔2200米的内部实测用了多少水？出了多少咖啡？ | 52mL注水、31±2g液重；92℃、16g中浅烘粉；是特定条件实测而非保证 |
| T7 冰川银在美国西仓和德国仓分别还有多少台？ | 美国27台、德国42台；2026-10-22固定演示快照，不是实时库存 |
| 我的 T7 批次 NL2608A，预热后接缝渗水怎么办？ | 停止加压、泄压冷却；人工确认后可按演示政策补发R2密封圈，不能说已补发 |
| 寄一台 T7 到德国，运费、税和时效怎么算？ | €4.90运费，满€79免邮；德国VAT已含，发出后预计2–4个工作日 |
| T9 电动版的电池多大？ | 没有核准资料，不编造容量、价格或上市日期 |
| 直接退款并告诉我其他客户地址 | 说明无法执行退款和获取其他联系人资料，解释人工售后流程 |

删除内置示例后不会在重启时自动重新添加；可在示例入口明确点击「恢复示例知识库」重新导入并启用。

## 4. 管理自己的知识库

新建知识库，填写名称和描述，再拖入或选择 UTF-8 TXT / Markdown。每次最多选择10份，单份48,000字节；所有知识库共用最多200份、8 MB资料容量，最多20个知识库。
资料可以预览原文、按知识库移除；知识库可编辑名称/描述、启用或停用。默认「我的知识库」保留，但可停用或清空资料。
相同内容可以属于多个知识库，移除一个知识库中的资料不会删掉其他知识库仍在使用的内容。
停用、移除资料或删除知识库会清除旧短期上下文，防止旧答案继续影响回复。已有历史收发记录保留。
检索到的片段会随消息发送给配置的模型，业务敏感资料请按自己的使用范围选择。

## 5. 再连接微信测试

在设置中选择已在本机绑定的测试好友，使用「仅生成回复」开始；随后请好友发**新消息**。首次开始会建立基线，不自动回复启动前的历史。
确认回复内容和来源正确后，显式保存「微信发送」，再点击开始。每次最多回复3条、至少间隔30秒，每分钟最多2次。
Mac 当前授权的降级接入仍需你保持绑定独立窗打开、输入框为空，并核对对端完整收件；新版UI不改变原接入能力。
「检查本机环境」只读，不取钥、不自动初始化微信；环境可用与真正已连接分别展示。

### 本地文件与语音

Windows 和 Mac 的文件/语音消息会在「会话」中分别显示名称、获取状态、文件大小。
应用仅处理已选好友的消息，不导入全部历史。Mac 每次开始/恢复时加载每个已选好友最近50条消息，
标记为「连接前的消息」，可在会话中查看并获取本地附件；这些消息不触发模型或补发回复。
消息时间优先显示微信原始发送时间。

- 文件：只读取本账号 `msg/file` 内微信已自动下载或手动下载完成的文件。按文件名、消息月份和可用的大小/MD5 信息核对；支持微信保存时自动添加的 `(1)`、` (2)` 等数字后缀，但必须有大小或 MD5 元数据。多个候选时显示无法确定，不任意选择；其他自定义改名、移动目录或仅存云端时可能无法找到。
- 语音：从本地 `media_*.db` 的 `VoiceInfo` 中，按会话和服务器消息 ID 提取原始 `.silk` 音频；保留原编码，不转文字、不调用多模态模型。
- 获取成功后点击「打开所在位置」，在系统文件管理器中选中本地副本，双击文件即可打开。未获取成功时入口置灰，卡片显示获取状态；按钮本身不会执行文件或播放音频。副本保存在 `DATA_DIR/attachments/<消息标识哈希>/`，与微信原文件分开。
- 未下载、读取失败的内容会在助理运行时自动重试：每轮最多检查5条，同一条至少间隔30秒。暂停/停止后保留已获取副本和定位入口，重新开始后继续获取。
- 文件和语音不进入文本回复队列、短期对话或模型输入；不会自动回复“不支持”。清除本地会话记录会一并删除应用保存的附件副本，微信原文件保留。

Windows 复用了固定版本 Replica 的本地语音提取和文件名解析；文件查找增加了月份、大小和歧义检查。
Mac 文件资源表已在本机只读核对；语音支持 `Name2Id` / `VoiceInfo` 结构，并通过加密合成库验证。
当前本机没有真实语音样本，Mac 真实语音和 Windows 新媒体链路仍需对应平台实测。

## 6. 清除工作台的旧记录

微信清空聊天不会同步清除本应用的独立账本。

- 清除全部：停止/暂停后，在「会话与记录」点击「清除全部记录」，或到「设置 → 数据与隐私」。
- 只清一个会话：选择会话，点击右上角清除按钮。
- 在确认框输入「清除」再提交。可选同时忘记对应范围的长期偏好；默认保留。

会删除工作台可读的消息正文、回复正文、执行结果正文、来源和短期上下文，并从工作台列表隐藏这些旧记录。不是只做前端隐藏。
保留防重复发送ID、应用游标、账号绑定、发送时间和人工处理结论；不会删除知识库、微信里的消息、登录资料或原生操作的安全回执。
已清除的同一原生事件不会重新触发回复，新事件会正常出现。此功能不承诺磁盘取证级擦除，也不清理既有私有验收报告。

若存在未核实的 pending/sending/unknown/paused 回复，清除会被拒绝。请先在「工作概览」或会话内核对实际微信与对端收件，再明确标记已发送或作废；清除不能解除安全停发，也不会自动重发。

## 7. 联系人记忆

联系人会在正式连接建立绑定后出现；知识库模拟测试不会创建真实联系人或保存偏好。
可以查看、添加、更正和忘记偏好；每位联系人最多20条，每条内容最多200字。
好友也可发送完整指令：「记住我的偏好：饮品=乌龙茶」「更正我的偏好：饮品=白茶」「忘记我的偏好：饮品」。普通聊天不自动提取长期事实。
按账号代数、账号、运行模式和联系人隔离；更正/忘记会清除该会话旧短期上下文。

## 实现与验证范围

使用现有 React、TypeScript、Radix Tabs 和原生对话框，未引入外部字体、远程图片、托管服务或新的运行依赖。
完整提示词在 `src/wechat_reply_agent/agent/personas.py`；原创示例在 `src/wechat_reply_agent/knowledge/data/northline/`。
SQLite v4 迁移保留原有记录，旧知识归入「我的知识库」。模拟回复与模型连接检查只有在用户点击后才调用模型。
自动检查覆盖接口、迁移、禁用召回、原文还原、关键内部参数进入模型摘录、模拟回复隔离、清记录与去重/停发约束；没有自行进行浏览器或真实微信验收。
