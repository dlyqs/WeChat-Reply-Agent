# 产品手册｜TrailPress T7 / PocketMill M2

所有数字均为虚构产品数据，仅供问答演示。

TrailPress T7 便携手压意式咖啡机：手动加压，无电池、无加热功能，需要外置热水。冰川银 SKU 为 T7-ICE-2609，火山黑 SKU 为 T7-BLK-2609。净重 612g，尺寸 72×198mm，标准粉碗容量 16g，可用范围 14–18g，水仓标线 60mL。推荐 90–94℃ 热水，标称萃取压力 8–9bar。美国售价 $89，德国售价 €85（含德国 VAT）。标配粉碗、量杯、清洁刷和 R1 常温密封圈，不含磨豆机。

PocketMill M2 手摇磨豆机：净重 468g，38mm 钢磨芯，单次容豆 22g。每转 30 格，归零点轻触即可，不可强拧。T7 意式研磨建议从归零后 14 格开始，再根据豆子和流速微调；手冲通常 24–30 格。美国售价 $59，德国售价 €55。

FieldKit F1 出行收纳套件：仅为收纳包和擦拭布，不包含咖啡机或磨豆机。美国售价 $19，德国售价 €18。它不是防水箱，不能浸水或高温消毒。

T7 适合已有热水条件的出差、露营和小办公室；不适合期待自动加热、一键全自动出杯的用户。现有产品不支持胶囊。知识库没有 T9 电动版或任何未上市机型的核准资料。
